2. GCS PLACEMENT IMPROVEMENTS (MapPage.py, GUI.py)
================================================================================

BEFORE:
- After mavlink connection, user was automatically prompted to click map for GCS
- Clicking map opened a confirmation popup asking "Confirm this as GCS location?"
- No way to remove or reposition GCS once placed

AFTER:
- Added explicit "Place GCS" button (disabled until mavlink connected)
- Ghost marker follows cursor showing preview of GCS placement
- Single click places GCS immediately (no confirmation popup)
- Button changes to "Remove GCS" after placement
- Can remove GCS and re-place if needed
- "Remove GCS" button disabled once polygon drawing starts

NEW METHODS (MapPage.py):
- toggle_gcs_placement(): Handles Place/Remove/Cancel states
- _load_gcs_icon(): Pre-loads GCS icon for preview marker
- update_gcs_preview(): Updates preview marker position on mouse move
- cancel_gcs_placement(): Cleans up when user cancels placement mode
- finalize_gcs_placement(): Cleans up after successful placement

STATE VARIABLES ADDED:
- gcs_preview_marker: Tracks the ghost preview marker
- gcs_motion_binding: Tracks mouse motion event binding
- gcs_icon: Pre-loaded GCS icon for markers

GUI.py CHANGES:
- Added gcs_location and gcs_marker initialization
- Modified call_mavlink_connection() to enable Place GCS button
- Modified set_gcs_location() to remove confirmation popup parameter
- Removed confirmation popup destruction code

3. POLYGON EDITING CONTROLS (MapPage.py)
================================================================================

BEFORE:
- No way to undo or reset polygon vertices during creation
- If user made a mistake, no recovery option

AFTER:
- "Undo Last Point" and "Reset" buttons appear during polygon editing
- Undo removes the last placed vertex
- Reset clears all vertices and starts over
- Buttons automatically hide when polygon is finalized

NEW METHODS:
- undo_last_polygon_point(): Removes last vertex, recreates polygon
- reset_polygon(): Clears all vertices, resets state

BUTTON BEHAVIOR:
- Buttons appear at row 4 when editing starts
- Other buttons (Start Mission, Debug) shift down during editing
- Buttons hide and layout restores when editing completes

BUG FIX:
- Fixed polygon point tracking (was commented out)
- Changed to delete/recreate polygon on each point for consistency with undo

5. MAVLINK COORDINATE CONVERSION FIX (GUI.py, Drone.py)
================================================================================

PROBLEM:
- MAVLink sends coordinates as scaled integers (multiply by 1e-7 for degrees)
- Coordinates like (286024869, -811927199) instead of (28.6024869, -81.1927199)
- This caused "math domain error" and incorrect map positioning

SOLUTION:
- Centralized coordinate conversion in GUI.py updateDronePosition()
- Detects scaled format (abs(lat) > 90 or abs(lon) > 180)
- Converts by dividing by 1e7
- Removed redundant conversion from Drone.py setPosition()
